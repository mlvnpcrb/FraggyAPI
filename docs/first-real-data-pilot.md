## Remaining blockers

1. Verify WDQS-specific robots/current endpoint policy and operational availability;
   policy-page accessibility does not prove the collector's pinned public network
   path works in this cloud runtime. Do not bypass the environment proxy policy.
2. Supply/review actual eligible fragrance IDs and a coverage plan without running
   unapproved discovery. Sparse brand statements or ambiguous names may make
   Wikidata inadequate as a complete commercial perfume catalog.
3. Set a real, monitored operator contact User-Agent; fixture contacts are invalid
   for a live pilot. Confirm request encoding/compression etiquette.
4. Prepare private exact manifest/collection evidence, expiry and attribution;
   trusted local operator review must pass collection and storage independently.
5. Obtain the user's separate explicit pilot authorization. No grant has been
   created in the application database, and external access remains off.
6. For any real image pilot, independently obtain the exact additional image rights.
   Nothing about CC0 metadata resolves photography, trademarks or trade dress.

Offline readiness is demonstrated using 100 original fictional source-style
records and original raster artwork. **Genuine dataset readiness: 0 imported,
0 published, 0 genuine image assets.** The safe integration can be reviewed while
these external authorization/coverage blockers remain unresolved.
