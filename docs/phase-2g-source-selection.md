# Phase 2G — first-source selection

Verified on **2026-10-19 (Asia/Manila)**. Research fetched policy/documentation
pages and robots files only, using ordinary HTTPS GETs. No fragrance queries,
product datasets, photographs, authentication, bypasses or paid services were used.
HTTP statuses below describe this environment's observation, not permission.

## Decision and ranking

1. **Wikidata structured entity metadata** is selected for the offline integration.
   Its official CC0 licensing and documented programmatic access offer the clearest
   commercial database route. Overall classification: **pending verification** of
   the exact operational endpoint/robot policy, pilot IDs, contact identity and
   user approval. CC0 eligibility is verified; collection is not activated.
2. **Direct manufacturer/brand partnership** is the preferred eventual image route.
   Seek an explicit grant for metadata and product photography independently.
3. **Authorized distributor/affiliate feeds** could supply product identifiers,
   sizes and images, but affiliate display rights are not automatically a license
   to resell a database or deliver images through an independent developer API.
4. The seven existing website candidates remain disabled. Parfumo, The Perfume
   Society and ScentBase explicitly require permission for the proposed reuse.
5. Existing Phase 2E scraped/open-repository candidates do not become authorized
   because their hosting repository or scraping code has a software license.

No real source has been approved in PostgreSQL. No source is automatically
licensed by this document. The seven registry policies remain `pending_review`.

## Official evidence URLs

- [Wikidata licensing](https://www.wikidata.org/wiki/Wikidata:Licensing), HTTP 200;
  observed revision `2548950862`: “All data in Wikidata has a CC0 license.” Scope
  is structured entity data, not project prose, third-party photographs or brands.
- [Wikidata data access](https://www.wikidata.org/wiki/Wikidata:Data_access), 200:
  official APIs, EntityData JSON, SPARQL GET/POST, dumps, request etiquette.
- [Wikimedia API usage guidelines](https://foundation.wikimedia.org/wiki/Policy:Wikimedia_Foundation_API_Usage_Guidelines),
  200: identify operators, honor throttling/content licenses/robot policy; numerical
  limits may change; content republication under its license remains permitted.
- [User-Agent policy](https://foundation.wikimedia.org/wiki/Policy:Wikimedia_Foundation_User-Agent_Policy),
  200: descriptive agent and current contact details.
- [Terms of Use](https://foundation.wikimedia.org/wiki/Policy:Terms_of_Use), 200:
  reuse must comply with underlying licenses and other applicable restrictions.
- [Wikidata robots](https://www.wikidata.org/robots.txt), 200;
  [WDQS robots](https://query.wikidata.org/robots.txt), environment CONNECT 403
  before an origin response. Endpoint verification remains outstanding.
- [Parfumo legal notice](https://www.parfumo.com/legal-notice), 200, Copyright.
- [Perfume Society terms](https://perfumesociety.org/terms-conditions/), 200,
